기존 현장 업데이트 방법 (통합웹빌더 32.2 (빌드 20260930-1))
=====================================================================
쓰는 파일 : 02_기존현장_UPDATE_업데이트용.zip
이 묶음은 "관리자 · 에디터 · API 기능" 만 최신으로 바꿉니다.

 1. (권장) 관리자 → 시스템 · 백업 → [지금 백업] 을 한 번 눌러 둡니다.
 2. ZIP 을 풀고 www 폴더 "안의 내용" 을 서버 /www 에 덮어씁니다.
 3. 브라우저에서 관리자( 도메인/admin/ )를 새로고침합니다. (Ctrl+F5)
 4. 에디터에서 [게시] 를 한 번 눌러 주면 공개 홈페이지의 편집용 스크립트도 최신이 됩니다.

덮어쓰지 않는 것 (그대로 유지됩니다)
---------------------------------------------------------------------
· /www/api/config.php        (현장 설정 · DB 접속)
· /www/api/private-config.php (개인 비밀설정)
· /www/api/data/             (방문예약 · 계정 · 게시 이력 등 모든 데이터)
· /www/.htaccess · /www/api/.htaccess
· /www/index.html 과 assets/ (현장 홈페이지 디자인 · 이미지)

· 그래서 현장명 · 대표번호 · 예약 · 관리자 계정 · Solapi · Google Sheet 설정 · 게시 데이터는 모두 그대로입니다.
