홈페이지 디자인 www 교체 방법 (통합웹빌더 32.2 (빌드 20260930-1))
=====================================================================
쓰는 파일 : 03_홈페이지디자인_ONLY_www_템플릿.zip (또는 새로 받은 디자인 www ZIP)
이 묶음에는 관리자(admin) · API(api) · 설치(install) 가 들어 있지 않습니다.
들어 있는 것 : index.html · assets(이미지 · 글꼴 · CSS · JS) · admin/tpl(게시 원본 + 이 디자인의 화면 데이터)
그래서 덮어써도 관리자 · 예약 데이터 · 설정은 건드리지 않습니다.

 1. ZIP 을 풀고 www 폴더 "안의 내용" 을 서버 /www 에 덮어씁니다.
 2. 관리자 → 에디터 → 왼쪽 [페이지] → [공개 홈페이지에서 페이지 가져오기]
 3. 페이지 목록이 새 디자인 기준으로 바뀌면 끝입니다.
 4. 필요하면 에디터에서 내용을 고치고 [임시저장] → [게시] 하세요.

주의
---------------------------------------------------------------------
· 디자인 ZIP 에는 admin/ · api/ 가 없으므로 그 폴더는 그대로 두세요. (지우면 관리자가 사라집니다)
· 현장명 · 대표번호는 관리자 설정값을 쓰므로 HTML 을 직접 고치지 않아도 됩니다.
