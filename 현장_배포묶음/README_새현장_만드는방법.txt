새 현장 만드는 방법 (통합웹빌더 32.2 (빌드 20260930-1))
=====================================================================
준비물 : 새 카페24 호스팅(도메인) · FileZilla · 01_신규현장_MASTER_설치용.zip

 1. FileZilla 로 새 서버에 접속합니다.
 2. 01_신규현장_MASTER_설치용.zip 을 풀고, 그 안의 www 폴더 "안의 내용 전부" 를 서버 /www 에 올립니다.
    (www 폴더째로 올리지 말고, 안에 있는 admin · api · assets · install · index.html 을 올립니다)
 3. (선택) 개인 비밀설정 파일이 있으면 private-config.php 를 /www/api/ 에 함께 올립니다.
    → Google Sheets · 문자(Solapi) 설정을 새로 입력하지 않아도 자동 연결됩니다.
 4. 브라우저에서  https://새도메인/install/  접속
 5. 현장명 · 대표번호 · 최고관리자(이름 · 아이디 · 비밀번호 · 이메일 · 휴대전화) 입력 → 설치
 6. 설치가 끝나면  https://새도메인/admin/  으로 들어갑니다.
 7. 새 홈페이지 디자인 www (03 번 ZIP 또는 새로 받은 디자인) 를 /www 에 덮어씁니다.
 8. 관리자 → 에디터 → 왼쪽 [페이지] → [공개 홈페이지에서 페이지 가져오기]
    → 새 홈페이지의 페이지들이 관리자에 자동 등록됩니다.
 9. 관리자 → 시스템 · 백업 → 방문예약 문자 알림
    → [Solapi 등록값(/32) 복사] 를 누르고, Solapi 사이트의 API Key 허용 IP 에 붙여 넣어 한 번 추가합니다.
      (모든 현장이 같은 Solapi 계정을 쓰므로, 서버가 새로 생길 때마다 이 IP 한 줄만 추가하면 됩니다)
10. 홈페이지에서 방문예약을 1건 넣어 봅니다.
    → 관리자 [방문예약 관리] 에 뜨고 · 문자가 오고 · 공용 Google Sheet 에 한 줄 쌓이면 완료입니다.

자주 묻는 것
---------------------------------------------------------------------
· 관리자 주소는 어떤 현장이든 항상  도메인/admin/  입니다.
· 대표번호는 설치할 때 한 번만 넣으면 헤더 · 푸터 · 퀵메뉴 · 전화버튼에 모두 쓰입니다.
  나중에 바꿀 때는 에디터 → [헤더] → 대표번호 → [전체 적용] 을 쓰세요.
· Google Sheet 는 모든 현장이 하나를 같이 씁니다. 첫 칸(사이트)에 현장명이 들어가 구분됩니다.
· 설치가 끝난 뒤 /install/ 에 다시 들어가도 초기화되지 않습니다. (안내 화면만 나옵니다)
· 현장끼리 예약 · 계정 · 설정은 서로 보이지 않습니다. (서버가 완전히 다릅니다)
