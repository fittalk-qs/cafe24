0-1. ★ 게시 실패 [API 404 · api/sites/1/publish-result] 의 원인과 해결 (이번 수정)
---------------------------------------------------------------------
  · 원인 : 카페24 서버가 **100KB 가 넘는 JSON 요청을 PHP 로 넘기지 않고 404** 로 막습니다.
           (직접 확인 : 같은 주소에 1KB · 100KB → 401(정상 도달) / 128KB 이상 → 404)
           게시 파일(index.html)이 약 613KB 라서 [게시 데이터 생성 → 공개 서버로 전송] 단계에서 404 가 났습니다.
  · 해결 : 큰 요청은 **파일 첨부(multipart) 형식**으로 보냅니다. (같은 크기의 파일 첨부는 서버가 정상 통과시킵니다 — 확인 완료)
           · 관리자 : 요청 내용이 90KB 를 넘으면 자동으로 파일 첨부 방식으로 전환 (게시 · 페이지 초안 저장 등)
           · 서버(api/index.php) : 첨부된 __json 파일을 요청 본문으로 읽고, _method 로 원래 방식(PUT 등)을 복원
           · 혹시 파일 첨부를 막는 서버라면 자동으로 원래 JSON 방식으로 한 번 더 시도합니다.
  · 이 수정은 관리자(www/admin/app-core.js)와 서버(www/api/index.php) 둘 다 올려야 동작합니다.

4. 신규 현장 설치 방법 (예 : 오산 현장 서버)
---------------------------------------------------------------------
  같은 ZIP 을 새 현장 서버에 설치합니다. 프로그램을 새로 만들 필요가 없습니다.
  1) 새 현장 카페24 서버 /www 에 ZIP 의 www 안 내용 전체를 올립니다. (2번과 같은 방법)
  2) 새 현장 서버에 설정 파일을 만듭니다 : /www/api/config.example.php 를 내 PC 로 받아 이름을 config.php 로 바꾸고
     아래처럼 채운 뒤 /www/api/config.php 로 올립니다. (다른 값은 지워도 됩니다)

        <?php
        return array(
          'secret' => '(아무 영문 · 숫자 40자 정도 — 현장마다 다르게)',
          'db' => array('driver' => 'sqlite'),
          'sms' => array(
            'provider' => 'solapi',
            'api_key' => '(Solapi API Key)',
            'api_secret' => '(Solapi API Secret)',
            'sender' => '(Solapi 에 등록된 발신번호)',
          ),
        );

     · DB 는 /www/api/data/ 에 자동으로 만들어집니다 (접근 차단 파일도 자동 생성).
     · 목동 서버의 config.php 를 그대로 복사하지 마세요 (secret 은 현장마다 달라야 합니다). Solapi 키는 같은 계정을 써도 됩니다.
  3) https://새현장도메인/admin/ 접속 → "처음 설정" 화면 (5번)
  4) 로그인 → [에디터] → 페이지 확인 · 수정 → [게시하기]
     · 처음 설치 직후의 index.html 은 목동 홈페이지 파일입니다. 첫 [게시하기]를 누르면 새 현장의 내용으로 다시 만들어집니다.
     · 이미지 · 글꼴(/www/assets/)은 ZIP 에 없습니다. 목동 서버의 /www/assets/images · /www/assets/fonts 를 내려받아
       새 서버 /www/assets/ 에 올린 뒤, 현장 이미지는 관리자 [에디터] · [미디어]에서 바꾸세요.
  5) 방문예약 1건 → 문자 제목이 새 현장명인지 확인


5. Google Sheets 방문예약 자동 누적 (Apps Script 웹앱) — 권장
---------------------------------------------------------------------
  방문예약이 접수되면 : 카페24 DB 저장 → 고객 화면 "접수 완료" → 문자 발송 → Google Sheet 에 한 행 추가
  (DB 가 원본입니다. 시트 · 문자 가 실패해도 예약 접수는 정상으로 끝납니다)

  [1] Google Sheet 준비
      · 데이터를 넣을 스프레드시트를 엽니다. (예 : 통합 시트의 "데이터 누적" 탭)
      · 탭 이름을 기억해 두세요. 없는 이름을 넣으면 "시트를 찾을 수 없습니다" 라고 알려 주고 아무것도 만들지 않습니다.
  [2] Apps Script 붙여넣기
      · 확장 프로그램 → Apps Script → 기존 코드를 지우고, 이 배포본의 google-apps-script/Code.gs 전체를 붙여넣기
      · 톱니바퀴(프로젝트 설정) → 스크립트 속성 → 속성 추가
          이름 : WB_SECRET   값 : 아무 문자열 20자 이상 (예 : mokdong-2026-abcd1234efgh)
      · (선택) WB_SHEET = 기본 탭 이름
  [3] 배포
      · 배포 → 새 배포 → 유형 [웹 앱] · 실행 사용자 [나] · 액세스 권한 [모든 사용자] → 배포 → 권한 승인
      · 웹 앱 URL 복사 (https://script.google.com/macros/s/…/exec)
      ※ 코드를 고치면 배포 → 배포 관리 → 편집 → 새 버전 → 배포 를 눌러야 반영됩니다.
  [4] 관리자에 입력
      · 관리자 → 사이트 설정 → [외부 연동] 탭 (최고관리자만 보임)
      · Google Sheets 사용 체크 → 연결 방식 [Apps Script 웹앱]
      · 웹앱 주소 : [3] 의 URL      공유 비밀키 : [2] 의 WB_SECRET      시트(탭) 이름 : 예) 데이터 누적
      · [연결 테스트] → "Google Sheets(웹앱) 연결 성공" → [설정 저장]
      ※ 서버 설정(api/config.php)에 google_sheet_webhook_url · google_sheet_secret · google_sheet_tab_name ·
        google_sheet_enabled 을 넣어 두면 관리자에서 비워 두어도 그 값을 씁니다. (기존 DB · Solapi 설정은 그대로 두세요)
  [5] 시트에 들어가는 열 (한 예약 = 한 행)
      사이트(현장)명 | 담당자 대표번호 | 유입 페이지 | 추출 경로 | 성함 | 연락처 | 방문날짜 | 방문시간 |
      접수시간 | 접수ID | 시도횟수 | 문의사항
      · 현장명 · 대표번호는 [사이트 설정] 값을 자동으로 씁니다 (코드에 고정되어 있지 않음 → 새 현장도 그대로 사용)
      · 빈 시트면 첫 줄에 위 제목을 자동으로 만들고, 이미 있으면 그대로 이어서 추가합니다.
  [6] 중복 · 실패 처리
      · 같은 접수ID 는 시트에 한 번만 들어갑니다 (Apps Script 쪽 + 서버 기록 둘 다 확인)
      · 실패하면 서버에 pending → failed 로 기록하고, 잠시 뒤 · 다음 관리자 요청 때 자동 재시도(최대 3회)
      · 예약 상세에 "구글시트 ✓ 동기화 완료 / ⚠ 동기화 실패" 와 [구글시트 다시 보내기] 버튼
      · 외부 연동 카드에 연결 상태 · 마지막 성공 시간 · 성공/실패/대기 건수 · [연결 테스트] · [기존 방문예약 동기화]
  [7] 안전
      · 웹앱 주소 · 비밀키는 서버에만 저장되고 공개 홈페이지 · 관리자 응답에 값이 나오지 않습니다 (등록 여부만 표시)
      · 고객 정보는 HTTPS POST 본문으로만 보냅니다 (주소에 이름 · 전화번호를 넣지 않음)
      · 오류 기록에는 고객 이름 · 전화번호를 남기지 않습니다.
  [8] 문제 확인 순서
      · 연결 테스트 실패 "비밀키가 맞지 않습니다" → Apps Script 의 WB_SECRET 과 관리자 입력값이 다릅니다.
      · "시트를 찾을 수 없습니다" → 탭 이름 오타 · 다른 스프레드시트에 배포했는지 확인
      · "Google 웹앱에 연결하지 못했습니다" → 배포 액세스 권한이 [모든 사용자] 인지, 새 버전으로 배포했는지 확인
      · 예약은 들어오는데 시트만 비어 있음 → 외부 연동 카드의 대기/실패 건수 확인 → [기존 방문예약 동기화]

9. Solapi(문자) 연결 방법
