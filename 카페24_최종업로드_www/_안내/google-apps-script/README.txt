방문예약 → Google Sheet 자동 입력 (Apps Script 웹앱 방식)
=====================================================================
구글 클라우드 · 서비스 계정 JSON · API 키 가 필요 없습니다.
카페24 서버는 "웹앱 주소 + 비밀키" 두 가지만 알고 있으면 됩니다. (서버에만 저장 · 홈페이지 JS 에는 절대 들어가지 않습니다)

넣는 열 (이미 만들어 두신 머리글 그대로)
  A 선택   B 사이트   C 접수일시   D 성함   E 연락처   F 방문일   G 시간   H 상태   I 문자   J 문의사항

예) 목동윤슬자이 | 2026-09-29 14:10 | 홍길동 | 010-1234-5678 | 2026-09-30 | 16:30 | 신규 | 1명 발송 완료 | 문의드립니다.


하실 일 (순서대로 · 10분)
---------------------------------------------------------------------
 1. Google Sheet 열기
    https://docs.google.com/spreadsheets/d/1mAwu5V2vfm3JuCMImjsEpWx50T84F8FrYN4Pm2QboKM/edit
 2. 상단 메뉴 [확장 프로그램] → [Apps Script]
 3. 이 폴더의 Code.gs 전체를 복사해 편집기에 붙여 넣고 저장 (Ctrl+S)
 4. 왼쪽 톱니바퀴(프로젝트 설정) → [스크립트 속성] → [속성 추가]
       이름 : WB_SECRET
       값   : 아무 문자열 20자 이상 (예: wb-mokdong-2026-0929-7f3a1c)  ← 이 값을 그대로 관리자에도 넣습니다
       (선택) 이름 : WB_SHEET   값 : 시트1
 5. 오른쪽 위 [배포] → [새 배포] → 톱니바퀴에서 유형 [웹 앱] 선택
       설명        : 통합웹빌더 방문예약
       실행 사용자 : 나
       액세스 권한 : 모든 사용자     ← 반드시 "모든 사용자" (카페24 서버가 호출합니다)
    → [배포] → 처음 한 번 [액세스 승인] → 본인 계정 선택 → "고급" → "…(안전하지 않음)으로 이동" → 허용
 6. 표시되는 웹 앱 URL 복사  (https://script.google.com/macros/s/AKfy…/exec)
 7. 관리자 로그인 → [시스템] (또는 사이트 설정) → [Google Sheets]
 8. 다음 값을 입력
       Google Sheets 사용 : 켜기
       Apps Script 웹앱 주소 : 6번 URL
       공유 비밀키           : 4번 WB_SECRET 과 똑같이
       시트(탭) 이름         : 시트1
       스프레드시트          : 1번 주소 붙여넣기 ([시트 열기] 버튼용 · 없어도 전송은 됩니다)
 9. [연결 테스트] → "연결 성공" 확인 → [설정 저장]
10. [기존 방문예약 동기화] → 지금까지 받은 예약이 시트에 채워집니다 (이미 있는 건은 건너뜀)
11. 홈페이지에서 방문예약을 1건 넣어 보기 → 시트1 에 새 행이 자동으로 추가되는지 확인
12. 끝. 이후 예약은 버튼을 누르지 않아도 자동으로 쌓입니다.


자주 나오는 오류
---------------------------------------------------------------------
"Google 로그인 화면이 돌아왔습니다"
   → 5번 액세스 권한이 "모든 사용자" 가 아닙니다. [배포 → 배포 관리 → 편집(연필) → 액세스 : 모든 사용자 → 배포]

"비밀키가 맞지 않습니다"
   → 4번 WB_SECRET 과 관리자 [공유 비밀키] 가 다릅니다. (앞뒤 공백 주의)

"시트(탭)를 찾을 수 없습니다"
   → 관리자 [시트(탭) 이름] 과 스프레드시트 아래쪽 탭 이름이 달라서 그렇습니다. 기본값은 시트1 입니다.

Code.gs 를 고친 뒤 반영이 안 될 때
   → [배포 → 배포 관리 → 편집(연필) → 버전 : 새 버전 → 배포] 를 해야 새 코드가 적용됩니다. (URL 은 그대로)


동작 방식 · 안전장치
---------------------------------------------------------------------
· 방문예약 접수 → ① 카페24 DB 저장 → ② Solapi 문자 → ③ (응답을 보낸 뒤) 시트로 전송
  시트 전송이 실패해도 예약 저장 · 문자는 정상입니다. 실패는 관리자에 "동기화 실패" 로 남고 [다시 보내기] 로 재전송합니다.
· 같은 접수ID 는 여러 번 보내도 행이 하나만 생깁니다. (서버 기록 + Apps Script 양쪽에서 중복 방지)
· 개인정보는 HTTPS POST 본문으로만 보냅니다. 주소(쿼리)에는 이름 · 연락처를 넣지 않습니다.
· 자동 삭제 · 자동 파기 · 자동 익명화 기능은 넣지 않았습니다. 예약은 계속 누적됩니다.
· 시트에는 고객 이름 · 연락처 · 문의사항이 들어갑니다. 공유를 "링크가 있는 모든 사용자" 로 바꾸지 마세요.
